# Harnest 功能介绍

> 面向用户的能力说明书。
> **版本**：v1（2026-08-27）· 对应内核 bundle dsh-v0.1.1-rc.2 · 三端（Android / iOS / HarmonyOS）

---

## 这是什么

Harnest 是一款**完全在手机上本地运行**的 AI 智能体应用。它不依赖任何 PC 或服务端——对话、工具执行、文件生成全部在你的设备上完成，只有模型 API 请求会发往你自选的 LLM 供应商。

支持 **Android、iOS、HarmonyOS** 三端，体验一致。

---

## 一、对话体验

| 能力 | 说明 |
|---|---|
| **流式输出** | 回答逐字流出，思考过程单独折叠展示，可随时展开查看推理细节 |
| **推理强度四档** | reasoningEffort 支持 low / medium / high 等四档，简单问题省 token，复杂问题拉满 |
| **steer 对话引导** | AI 回答过程中随时插话纠偏，不用等它说完 |
| **中断与压缩** | 一键中断当前轮；上下文将满时可手动 compactNow 压缩，也可看水位条预知 |
| **上下文水位条** | 实时显示当前会话 token 用量占比，告别"突然失忆" |
| **编辑重发** | 修改任意历史消息并从该处重新生成 |
| **会话分叉（fork）** | 从任意历史节点复制出新会话，探索不同方向互不影响 |
| **消息评分** | 对回答打好评/差评，便于回溯质量 |
| **导出对话** | 会话内容导出保存 |
| **提问卡** | AI 需要澄清时会弹出结构化提问卡，点选/填写即答，对话不中断 |
| **记忆重放** | 杀掉 App 重开，会话完整恢复（事件日志逐条重放，不是残影缓存） |
| **深色模式 / 代码高亮** | 全端支持 |

## 二、工具与智能体能力

AI 不只是聊天——它带一整套工具链，在你的设备上真实执行：

| 能力 | 说明 |
|---|---|
| **文件读写（fs 三件套）** | AI 可在应用沙箱内读/写/编辑文件 |
| **联网获取（web_fetch / web_search）** | 抓取网页内容、执行搜索 |
| **子代理（task）** | 复杂任务自动拆分给子代理并行处理 |
| **run_script 沙箱脚本** | AI 编写并在设备本地沙箱中执行 JS 脚本，处理数据、转换格式 |
| **办公文档生成（OOXML）** | 直接产出真正的 **Excel (.xlsx) / Word (.docx) / PPT (.pptx)** 文件——"帮我做张表"得到的是能打开的表格，不是一段文本 |
| **后台任务（bg_timer / listJobs）** | 定时任务与长任务后台运行，可随时查看和终止 |
| **失败详情透出** | 模型请求失败时展示上游返回的真实错误（401/配额/参数错误…），不再是干巴巴的"请求失败" |

## 三、设备能力（手机端 computer use）

AI 可以操作你的手机（均需系统权限弹窗授权，每次调用用户可见）：

通讯录读写 · 日历事件管理 · 剪贴板 · 文件选择与沙箱读写 · 相册选图/保存 · 拉起邮件/拨号/短信 · 系统相机拍照 · 录音 · 打开其他应用 · 相机附图提问

**三端覆盖现状**：HarmonyOS 23/23 全覆盖 · Android 21/21 · iOS 9/21（持续补齐中）。

## 四、模型与供应商

- 内置 **deepseek-v4 系列等八家**供应商预设，填 key 即用；
- 支持自定义供应商端点与模型 ID；
- 配置支持**导入导出**（含 EMM 企业分发场景），换机/批量部署一键迁移；
- 配置自动版本迁移，升级 App 不丢设置。

## 五、隐私与安全

- **无服务端**：没有任何 Harnest 自有服务器经手你的对话；
- 会话、配置全部存于应用私有目录；
- 设备权限逐项弹窗申请，可永久拒绝，AI 每次设备调用都是用户可见动作；
- 沙箱脚本只能访问应用沙箱目录，碰不到系统其他数据。

## 六、已知限制

- 数学公式目前为降级渲染（三端），原生排版在路线图上；
- iOS 设备工具覆盖暂不及另两端；
- 消息排队（弱网/切换会话时不丢消息）目前为 HarmonyOS 独有。
